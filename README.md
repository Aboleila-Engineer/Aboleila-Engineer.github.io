# Saad Fakry — Portfolio

Live site: https://aboleila-engineer.github.io/

This repository powers my personal portfolio website through GitHub Pages.

## How to edit the site

You do not need any tools installed. Everything can be edited in the browser:

1. Open `index.html` in this repository.
2. Click the pencil icon (Edit this file).
3. Make your changes, then press **Commit changes**.
4. The live site updates by itself within a minute or two.

### Common edits

- **Change text (name, about, contact):** find the section in `index.html` and edit the text between the HTML tags.
- **Add a project:** in the `PROJECTS` section, copy one whole `<article class="card proj"> ... </article>` block, paste it below the others, and change the title, description, stack tags and GitHub link.
- **Remove a project:** delete its whole `<article> ... </article>` block.
- **Change colors:** edit the values at the top of the file under `:root` (for example `--accent`).

## Files

- `index.html` — the whole website (structure, styles and behavior in one file, with comments marking the editable parts).
- `README.md` — this guide.
